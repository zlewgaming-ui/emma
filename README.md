# Emma

Prywatna aplikacja do nauki angielskiego z wirtualną korepetytorką. Działa w całości w przeglądarce, bez serwera.

- Głos: Web Speech API (syntezator i rozpoznawanie mowy). Na iPhonie nagranie rozpoznaje Gemini.
- Rozmowa: Gemini API. Klucz każdy wkleja sam, zostaje w przeglądarce i nie ma go w tym repozytorium.
- Postępy: pamięć przeglądarki, opcjonalnie ukryty gist na GitHubie użytkownika, eksport i import do pliku.
- Instalacja: dodaj stronę do ekranu głównego telefonu.

Darmowy poziom Gemini ma ograniczenia regulaminowe w UE, dlatego ta kopia służy wyłącznie jej właścicielowi.
